\# StagePass



\## Concert Seat Reservation and Ticketing Management System



StagePass is a Java console-based application designed to manage concert seat reservations and ticket transactions.



\### Technologies

\- Java 17

\- Object-Oriented Programming (OOP)

\- Git and GitHub



\### Architecture

StagePass follows the Model-View-Controller (MVC) architecture with supporting Service and Repository layers.



\### Project Structure

\- model - Contains the application's data and domain classes.

\- view - Handles console input and output.

\- controller - Coordinates user interactions.

\- service - Handles business logic.

\- repository - Manages data storage and retrieval.



\### Main Features

\- Concert seat selection

\- Seat availability management

\- Ticket category and pricing

\- Customer information management

\- Payment simulation

\- Ticket generation
